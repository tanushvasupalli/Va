## 2024-10-23 - Database Connection Pooling
**Learning:** The project uses Supabase PostgreSQL for cloud storage (`core/storage.py`). Creating a new connection for every query creates significant latency overhead and leaks connections from constant TCP/TLS handshakes.
**Action:** Replace `psycopg2.connect()` with `psycopg2.pool.ThreadedConnectionPool`. When building connection pools with psycopg2, use a proxy wrapper class to handle context management safely. Crucially, the proxy must explicitly implement a `close()` method that returns the connection to the pool (`putconn`) and call this in `__exit__`. Additionally, the proxy must implement `__getattr__` to delegate other method calls (like `.cursor()`) to the underlying connection to prevent breaking standard psycopg2 functionality.
