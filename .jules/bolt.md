## 2023-10-24 - Supabase Connection Pooling & autocommit=True
**Learning:** Establishing direct connections to Supabase PostgreSQL for every query incurs significant TCP/TLS handshake latency. However, using `psycopg2.pool.ThreadedConnectionPool` with `autocommit=True` presents a conflict, as the native `psycopg2` connection `__enter__` block attempts transaction management which is forbidden in autocommit mode.
**Action:** When pooling connections for a database that requires `autocommit=True`, you must implement a `PooledConnectionProxy` class. This class should manage the `__enter__` and `__exit__` contexts directly (simply returning self and calling `close()` respectively). The proxy's `close()` method is responsible for releasing the connection back to the pool via `putconn()`, and a `__getattr__` implementation ensures all other standard connection methods function as expected.
