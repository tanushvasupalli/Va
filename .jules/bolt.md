## 2024-05-24 - psycopg2 autocommit and connection pooling context managers
**Learning:** When using `psycopg2` with `autocommit=True`, the native connection context manager (`__enter__`) will conflict as it attempts to manage transactions. When building connection pools, use a proxy wrapper class to handle context management safely. Crucially, the proxy must explicitly implement a `close()` method that returns the connection to the pool (`putconn`) and call this in `__exit__`, preventing `ProgrammingError` exceptions if the application attempts to close it directly. This matches project memory context!
**Action:** When wrapping psycopg2 connections for pooling, ensure the proxy correctly implements `close()` and handles `__enter__`/`__exit__` to return the connection to the pool, rather than relying on native psycopg2 context managers which conflict with `autocommit=True`.
